# title-Keeper-resource-pack

Minecraft Paper Server Plugin resource pack  for players to accept it (only for server use)
## how to setup 
1. go to any minecraft zip hosting web like [McPacks](https://mc-packs.net)
2. now go to your Server Root File And Edit Server.properties and the followig that was given in the next side like 
   is 
   ```text
   resource-pack=https://download.mc-packs.net/pack/thezipnamegivenbyit.zip
   resource-pack-sha1=yourgivensha1of30-40digit
   resource-pack-id=yougivenid
   resource-pack-prompt={"text":"Our server uses a custom resource pack!", "color":"gold"}
   require-resource-pack=true
   ```
   
   Now Done You Have Setup the Resource Pack
   ### NOTE- WE recommend That [Modrinth titlekeeper](https://modrinth.com/plugin/titlekeeper) resources packs are currently in review please download the resource from here by selecting the version.
